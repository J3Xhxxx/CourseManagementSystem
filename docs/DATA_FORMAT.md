# 项目文件格式

## CSV：上课时间数组与固定课程

UTF-8 编码，支持 BOM、LF/CRLF 换行、双引号包裹字段、字段内逗号/换行，以及用两个双引号表示一个引号。不支持 GBK 自动猜测。表头可以换序，未知、重复或缺失表头会报错。

样例和转换器输出统一使用 UTF-8 BOM，便于 Windows 表格软件识别中文。手工编辑后请按“CSV UTF-8”格式保存；普通 ANSI/GBK CSV 不可直接导入。出现打开乱码时先重新按 UTF-8 打开，避免把乱码内容另存回原文件。

必需表头：

```csv
课程代码,课程名称,授课教师,周次,上课时间,教室,学分,是否为固定课程
FIX101,高等数学,周老师,1-16周,"[(周一,1),(周四,3)]",H101,4,是
CS101,操作系统,李老师,"[1-5,7-9周]","[(周二,2),(周五,4)]",H205,3.5,否
```

| 字段 | 规则 |
| --- | --- |
| 课程代码、课程名称、授课教师 | 必填，去除前后空白，按文本精确匹配 |
| 周次 | 如 `[1-5,7-9周]`、`1-16周`、`1,3,5`；多组安排用英文分号分段，含逗号必须加 CSV 双引号 |
| 上课时间 | 每段为非空 `(星期,节次)` 数组，如 `[(周一,1),(周四,3)]`；多段用英文分号分隔，必须用 CSV 双引号包裹 |
| 教室 | 每段安排共用的教室，必填；多段用英文分号分隔 |
| 学分 | 有限非负数，同一教学班所有记录必须一致 |
| 是否为固定课程 | 必填“是”或“否”；同一教学班的所有行必须一致 |
| 单双周（可选表头） | 每周、单周、双周；空值等同每周，对本行每段周次集合进行过滤 |

数组逐项配对，不进行星期集合与节次集合的笛卡尔积。例如 `[(周一,1),(周四,3)]` 只有周一第 1 节、周四第 3 节两次课。星期接受 1～7、周一～周日、星期一～星期日，也接受周天、星期天；节次为 1～6，`1-2` 表示前两个完整时段的闭区间。允许元组周围有空白，不允许空数组、缺项或末尾逗号。

同一段数组内的各次课共享该段周次、教室。一个教学班的多组安排可用英文分号 `;` 保存在同一行；“周次”“上课时间”“教室”的分段数量必须相同，第 N 段逐项对应，不将各段周次与所有时段交叉组合。教室名称本身不能包含分号。例如：

```csv
课程代码,课程名称,授课教师,周次,上课时间,教室,学分,是否为固定课程
NET101,计算机网络,刘老师,"1-5,7-9周;1-4周","[(周二,1),(周四,1)];[(周五,1)]",N331;N331,3,是
```

这是一班三次课：周二、周四只在 1–5、7–9 周上课，周五只在 1–4 周上课。分段数不一致或有空段会整批报错。只有一段时不需要分号。

也可分行填写同一教学班，同一行只有一段时，所有时段共享周次、教室、单双周：

```csv
课程代码,课程名称,授课教师,周次,上课时间,教室,学分,是否为固定课程
CS101,操作系统,张老师,"[1-5,7-9周]","[(周一,1)]",H415,3.5,否
CS101,操作系统,张老师,"[1-5,7-9周]","[(周四,3)]",H416,3.5,否
```

不单独创建课程对象，教学班按“代码＋名称＋教师”归并。教师、教室等字段不自动进行同义词替换。当前只接受上述新表头，不读取旧的“星期、节次”分列格式。

完全相同的 Meeting（周次集合、星期、起止节次、教室均相同）会跳过，并按条上课安排计入重复数；同一数组内的重复项也会跳过。周次集合排序去重后比较；相同时间但不同教室不是重复数据，将报班内重叠错误。两条仅部分重叠的记录也会报错，不自动猜测合并含义。

“是”表示学校已经确定的必修教学班。同一课程最多有一个固定教学班；该班加入后不能修改、删除、取消必选或换班。完全重复导入可跳过，但不能通过再次导入增加或改变已固定班的安排。若初始数据录错，应更正 CSV 后新建项目重新导入。完整样例见 [fixed_courses.csv](../examples/fixed_courses.csv)。

相同课程代码但不同课程名将按两个课程处理，这是当前身份规则的结果。导入不用于改名或改学分，应调用数据管理接口完成修改。

空文件报错；只有合法表头的文件不增加数据；纯空行忽略。每一行必须具有与表头一致的字段数。

出现任何错误时整批导入不生效。行内容错误带物理行号，跨行引号字段之后的行号也会正确累计；整批的固定课程约束错误由服务报告。当前错误前缀为中文，部分模型验证原因使用英文。

## JSON：项目格式 version 4

GUI 按姓名保存到项目根目录下的 `accounts/姓名.json`，同名登录自动加载，保存覆盖同一文件。账号由文件名区分，JSON 内容结构不变，不增加密码或账号表。其他路径的 JSON 可在 GUI 中只读打开。命令行数据工具仍可指定输入、输出路径。

```json
{
  "version": 4,
  "semesterWeeks": 20,
  "teachingClasses": [
    {
      "code": "CS101",
      "name": "操作系统",
      "credits": 3.5,
      "teacher": "张老师",
      "isFixed": false,
      "meetings": [
        {
          "weeks": [
            1,
            2,
            3,
            4,
            5,
            7,
            8,
            9
          ],
          "weekday": 1,
          "startPeriod": 1,
          "endPeriod": 1,
          "classroom": "H415"
        }
      ]
    }
  ],
  "constraints": {
    "requiredCourseKeys": [
      "5:CS10112:操作系统"
    ],
    "lockedTeachingClassIds": [
      "5:CS10112:操作系统9:张老师"
    ],
    "forbiddenTimes": [
      {
        "week": 20,
        "weekday": 7,
        "period": 6
      }
    ]
  }
}
```

- 每个对象的上述字段均为必需字段；不支持的版本拒绝读取，多余字段忽略。
- weeks 保存展开后的整数周次，所以单双周信息已由实际周次完整表达。
- isFixed 必须是布尔值，表示学校固定课程，不能省略或填写字符串。
- 允许空 teachingClasses；不存在独立的课程记录；每个教学班必须至少有一个 Meeting。
- 分组键、教学班 ID 从代码等字段重新生成，位图和图索引也在读取时重建。约束引用生成的 ID，读取时检查引用是否存在。教学班重复 ID、越界时间、班内重叠和字段类型错误会被拒绝。
- 保存采用 QSaveFile 的临时文件＋提交方式替换，写入失败不直接覆盖旧文件。
- 当前格式保存学期、教学班、上课安排和用户约束；生成的方案暂不持久化。

### 约束字段

| 字段 | 规则 |
| --- | --- |
| requiredCourseKeys | 本次参与搜索的代码＋名称分组键集合，必须包含全部固定课程；每门恰选一个教学班。没有固定课程时，空数组才表示不选任何课程 |
| lockedTeachingClassIds | 个人锁定的教学班 ID 集合；教学班必须存在，所属课程必须在 requiredCourseKeys 中，同一课程最多锁定一个班，不能锁定固定课程的其他教学班 |
| forbiddenTimes | 禁止上课的具体时间点；每项包含 week、weekday、period 三个必需整数，分别限制在本学期周次、1～7、1～6 |

三个字段均为必需数组；悬空引用、越界或非整数时间被拒绝，重复项按集合自动合并。学校固定由 isFixed 表达，无需写入个人锁定集合。序列化时 ID 按字节序排列，禁止时间按“周次、星期、节次”排列，保证重复保存得到稳定结果。

约束可以在时间上无解：例如固定课程之间重叠、固定课程与个人锁定班重叠，或者固定/锁定班占用了禁止时间。此类设置可以保存并重新打开，由搜索报告没有可行方案及冲突位置；不会在加载时静默移除课程或禁止时间。

分组键是代码和名称各自的“UTF-8 字节长度 + 冒号 + 文本”串联；教学班 ID 再追加教师的同样表示。示例中“操作系统”为 12 个 UTF-8 字节，“张老师”为 9 个。建议由界面修改约束，避免手工计算 ID。教学班改名会同步维护该班的锁定与相关分组键引用，删除会清理相关引用。

### 版本校验

项目处于开发阶段，只读写当前 version 4 格式，不提供旧格式兼容或迁移。version 必须是整数 4，其他版本直接返回不支持版本的错误。teachingClasses 和 constraints 均为必需字段；版本或字段校验失败不会替换当前项目。

命令行 import 创建新项目；merge 读取输入 JSON 后合并 CSV，全部成功才写输出 JSON。新增代码＋名称组合默认加入必选集合；已有课程的必选状态、锁定和禁止时间保留。输出路径可以与输入 JSON 相同，提交前旧文件仍存在。输出目录需要预先存在。
