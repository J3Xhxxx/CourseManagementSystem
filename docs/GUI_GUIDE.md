# 界面指南：教学班管理、选课约束与方案生成

各按钮、菜单、下拉选项及禁用条件的完整说明见 [界面按钮与菜单说明.docx](界面按钮与菜单说明.docx)。

## 启动

在项目根目录执行：

```powershell
./scripts/build.ps1
./scripts/run.ps1
# 或直接加载样例
./scripts/run.ps1 -ImportCsv examples/courses.csv
# 带固定初始课表、一周多次课的样例
./scripts/run.ps1 -ImportCsv examples/fixed_courses.csv
```

构建和启动脚本默认使用 Release。启动脚本会检查程序旁的 Qt 和 MinGW 运行库，缺失时从已安装工具链自动部署；重新构建也会部署运行库。本机工具链位于 Codex 应用缓存的物理目录，脚本已兼容普通 PowerShell，无需手动配置 PATH。

## 界面操作

顶部只保留一排工具栏按钮，已移除重复的“文件、教学班、方案”菜单；原有键盘快捷键保留。

中央区域的“课表转换”页签与主课表并列，可读取学校 `.xls`，按课程名称归并为一个固定教学班、一行 CSV，预览并导出需要人工补齐编号、学分的草稿及审核说明。它不会导入或改变当前项目；第 9 行其它课程由人工核对、补充。操作详见 [TIMETABLE_CONVERTER.md](TIMETABLE_CONVERTER.md)。

1. 点击“新增教学班”，一次填写课程代码（代号）、名称、学分、教师、固定课程标记及上课安排，空项目也可直接新增。勾选“学校固定的必修课”后，该班加入即不可编辑或删除。
2. 代码＋名称＋教师共同标识教学班；左侧平铺展示完整记录，不再先创建或选择课程。
3. 每行安排填写周次、单双周、星期、起止节次、教室。周次可输入 `1-5,7-9` 或 `[1-5,7-9周]`；选择“单周/双周”会对该周次集合过滤。界面新建项目支持 1～104 周，默认 20 周。
4. 双击非固定教学班可以编辑全部字段，仅修改当前班，不改动其他教师的班。代码、名称或教师变化会更新该班身份。重复身份会提示错误，原数据保留。固定班的编辑、删除按钮禁用。
5. 中央始终保留学校固定初始课表；选中非固定教学班时，叠加显示该班在所选周的全部安排。周次框向下箭头增加一周，向上箭头减少一周。重叠格同时显示两门课及“时间冲突”。第六节为 20:45–22:30，星期列包括周日，其他周的课程不会叠加到本周。
6. 右侧“教学班冲突”页签列出不能与当前班同时选择的教学班，分别标注“时间重叠”和“同课程互斥”。冲突时间覆盖整个学期，按星期/节次合并显示具体周次，不受中央所选周过滤。
7. 双击冲突记录可以切换到对应教学班。搜索框可按代码、名称、教师、周次、星期、节次、教室筛选；多个条件用空格分隔。当前选择被筛掉时，清除该班预览和冲突详情；课表仍保留当前周的固定课程和禁止时间。
8. “删除”会明确确认，只删除当前非固定教学班及其上课安排。

教学班编辑窗口会将连续的单双周集合显示为等价的紧凑范围，例如 `2-20 + 双周`。不连续且不能如此表达的集合保留显式周次。鼠标悬停周次/教室字段可查看完整文本，双击文本单元格进行编辑。

## 固定课程、必选课程与个人锁定

点击工具栏“选课约束”，或切换右侧同名页签。每次勾选或更换教学班都会立即生效，无需额外点击“应用”。

学校固定课程的必选项始终勾选、不能取消，教师下拉框显示“学校固定”并禁用。它们不计入个人锁定数量。其余课程按下面规则设置：

1. 勾选本次要参与生成的课程，每门恰选一个教学班。未勾选的课程不会进入方案；左侧课程搜索框仅过滤显示，不影响这里的设置。新增或首次导入的课程默认勾选。
2. 在课程右侧下拉框选择教师，即锁定该教学班；若课程原先未勾选，会自动勾选。改选另一位教师会替换同一课程的旧锁定。
3. 下拉框选择“不锁定”会恢复该课程的所有可用教学班，但保留必选勾选。取消课程勾选则会同时解除其锁定。
4. 取消全部非固定课程后，生成结果仅包含固定初始课表；没有固定课程时才得到零课程空方案。

修改课程代码、名称或教师会同步维护约束引用。删除教学班会清除该班锁定；同代码＋名称仍有其他班时保留必选设置，最后一个班消失时清理该必选键。必选列表从教学班派生，不再持有独立课程实体。

## 禁止时间

在“选课约束”页签下半部分的“禁止上课的时间”边框内设置不允许上课的时间。起止节次框向下箭头增加，向上箭头减少，范围仍为 1～6：

1. 输入周次，如 `[1-5,7-9周]`；选择每周、单周或双周，再选择星期和起止节次。
2. 点击“添加禁止时间”，添加整个范围内的所有实际时间点。重复或重叠范围合并，不会累计出重复禁用。
3. 点击“解除此范围”，只移除输入范围覆盖的禁止时间，其他禁止时间保留。
4. 下方表格按“星期＋节次”合并列出周次。选择一行后点击“删除选中的禁止时间”，移除该行全部周次对应的时段；双击一行可把它的周次和时段载入上方表单，便于按范围解除。

例如 `1-20周 + 双周 + 周日 + 第6至6节` 只禁止第 2、4、…、20 周的周日第六节，不影响单周。中央课表按当前所选周显示红色“禁止上课”格；单班预览若与禁止时间重叠，会显示“与禁止时间冲突”。

非法周次或倒序节次会在面板内显示错误，原设置保留。时间上互相矛盾的有效设置可以保留，例如同时锁定两个有课时冲突的班；生成时会给出无解解释。

## 方案偏好优先级

“选课约束”页签最下方的“方案偏好优先级（软偏好，不影响合法性）”是软偏好设置，只决定合法方案之间的先后顺序，不参与“是否合法”的判断：

1. 列表按比较顺序从上到下排列，六项指标各出现一次：早课次数、上课天数、空堂节数、最大连续节数、最晚结束节次、空闲半天数。
2. 选中某一项后用“上移”“下移”调整它的优先级；靠上的指标先比较，只有它相等才继续比较下一项。
3. “恢复默认顺序”还原为“早课次数 → 上课天数 → 空堂节数 → 最大连续节数 → 最晚结束节次 → 空闲半天数”。
4. 前五项越小越好，空闲半天数越多越好；方向固定，不能通过调整顺序把某一项改成相反方向。
5. 调整优先级会立即记为未保存修改并清空上一次的搜索结果，需要重新点击“生成方案”。该设置随项目一起保存到 version 5 JSON。

指标定义、口径和手工算例见 [STAGE7.md](STAGE7.md)。

## 生成与浏览方案

1. 在新项目中导入 `examples/search_demo.csv`，保持默认约束，点击工具栏“生成方案”或按 Ctrl+G。该示例应得到 3 个合法方案；原 `examples/courses.csv` 只有 1 个。
2. 按“选课约束”中的必选集合生成，保证固定班及所有个人锁定班入选、每门必选课程恰选一个班、全部上课安排不进入禁止范围。
3. 右侧可设置最多保留的方案数（1～1000，默认 100，即 Top-K 的 K）、最多尝试教学班的次数（1～10000000，默认 100000）。生成在后台执行，可取消。
4. 搜索过程会评价每个合法方案，并用固定容量大根堆只保留当前较优的前 K 个；搜索完成后按偏好优先级从优到差显示。搜索跑完时保留的就是全局最优的前 K 个，被节点上限或取消打断时只表示“已探索部分中较优的方案”。
5. 搜索完成会自动显示第一个方案。点击列表或“上一个/下一个”切换，中央显示课程、教师、教室；周数控件按真实周次过滤。
6. 列表每行显示该方案的六项指标；下方方案详情重复指标、当前排序优先级和选中教学班。点击左侧教学班切回该班与固定课表的叠加预览；再次点击当前方案行可恢复完整方案。悬停课表单元格可查看完整文字。
7. 状态区明确区分搜索完成、搜索完成但方案多于保留上限、达到尝试上限、已取消：
   - “搜索完成：共 N 个合法方案（少于保留上限，已全部显示）”；
   - “搜索完成：共 N 个合法方案，按偏好优先级保留较优的前 K 个”；
   - “达到尝试上限，搜索未完成……不能视为全局最优”；
   - “搜索已取消，搜索未完成……不能视为全局最优”。
8. 候选班全被固定课表或禁止时间排除时，会列出课程名称。固定班/锁定班之间冲突、固定班/锁定班与禁止时间冲突时，还会列出具体教学班及重叠周次、星期和节次。其他组合无解时提示剩余教学班无法兼容；当前没有最小无解原因计算。
9. 修改教学班、选课约束、偏好优先级、导入新安排、新建或打开项目会取消搜索并清空过期方案。保存文件、完全重复导入以及未实际改变设置的操作保留方案。

结果按偏好优先级排列，第一行优先级最高；同一优先级下指标完全相同的方案按教学班 ID 稳定排序，因此同一份数据每次生成顺序一致。生成结果不写入 JSON，重新打开项目后需要再次生成；搜索本身不会产生未保存修改标记。

## 文件与未保存修改

- “新建”选择学期周数并创建空项目。
- “导入 CSV”合并到当前项目，规则沿用 [DATA_FORMAT.md](DATA_FORMAT.md)。失败时整批不生效；完全重复导入不新增修改标记。
- CSV 使用 `[(周一,1),(周四,3)]` 时间数组及“是否为固定课程”列（是/否）；周次或教室不同时可在同一行用英文分号分段，三列“周次、上课时间、教室”逐段对应，也可分行归并。同一固定班首次导入可以合并多行；加入后不能继续改变它，录错时更正源 CSV 并新建项目重新导入。
- “打开”“保存”和“另存为”仅支持当前 version 5 JSON 项目，将教学班、固定标记、约束和偏好优先级一起原子保存。其他版本直接报错，不执行迁移。首次保存或另存为会选择文件名，缺省扩展名为 .json。
- 窗口标题中的星号表示有未保存修改。新建、打开其他项目或关闭窗口时可选择保存、放弃修改、取消。
- 选择取消会保留当前项目；保存失败也不会继续关闭或替换项目。打开文件失败时原项目仍保留。
- 快捷键：Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存、Ctrl+Shift+S 另存为、Ctrl+I 导入。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| ProjectController | 持有项目、文件路径、修改状态；提交 TeachingClassService 数据及约束修改，调用 IO，并在成功后通知界面 |
| MainWindow | 工具栏、快捷键、各面板和文件对话框的协调，未保存处理 |
| TeachingClassPanel | 教学班列表、文本筛选，按稳定 ID 选择 |
| TeachingClassDialog | 输入和字段校验；支持一个教学班多条 Meeting |
| ConstraintPanel | 必选勾选、教学班锁定、禁止时间添加/解除/删除、方案偏好优先级上移/下移/恢复默认，将有效设置交给控制器 |
| TimetableWidget | 显示固定初始课表、所选班叠加预览或完整方案在指定周的安排，以及该周禁止时间 |
| TimetableConverterWidget | 运行独立转换脚本，按周预览学校固定课表，导出待人工完善的 CSV；不访问主体数据服务 |
| ConflictPanel | 展示既有冲突图的原因与时间点 |
| SearchController | 在项目快照上后台搜索、取消、丢弃过期结果 |
| CandidatePanel | 生成参数、状态、统计与方案列表，显示每个方案的六项评价指标和当前排序优先级 |
| ScheduleEvaluator | 按真实周次统计六项指标、校验偏好优先级、字典序比较与方案排序 |
| BoundedMaxHeap | 固定容量二叉堆，只保留按偏好排序较优的前 K 个方案 |

Qt 对象通过父子关系管理生命周期。Widgets 不实现课程增删改规则、冲突算法、评价算法或文件解析；界面不跨更新持有核心模型指针。

## 测试

构建脚本仅编译和部署，不运行自动化测试。界面操作按本指南手动验证；数据检查与性能对照命令见 [README.md](../README.md)。

第五轮约束实现、数据职责及边界语义见 [STAGE5.md](STAGE5.md)。[STAGE4.md](STAGE4.md) 保留第四轮基础搜索的历史说明；其“全部课程必选”规则已由显式必选集合替代。搜索默认采用动态 MRV＋Forward Checking，详见 [STAGE6.md](STAGE6.md)；评价指标、偏好排序与 Top-K 见 [STAGE7.md](STAGE7.md)。

搜索统计中，“提前排除”指当前分支中不兼容的候选删除次数，同一个候选恢复后在其他分支再被排除会再次计数。“无后续选择”指某门必选课程的候选已全部被当前选择排除，该分支立即回退；它不意味着整个项目无解，整体结论以搜索状态为准。“保留”指合法方案装满大根堆后仍然留在结果里的数量，可能小于搜索到的合法方案总数。
