# 方案评价、偏好排序与 Top-K

这一阶段在 main 现有功能上整合 6k 的评价与排序功能，保留账号、只读限制、增量冲突图、邻接表前向检查和独立转换器。CSV 仍要求人工补齐编号与学分，JSON 保持 version 4。

## 指标口径

全部指标按实际周次扫描时间位图，不将不同周叠成一周。

| 指标 | 计算方式 | 方向 |
| --- | --- | --- |
| 早课次数 | 每个真实上课日第一大节有课，记一次 | 少优先 |
| 上课天数 | 每个真实周次中有课的天数之和 | 少优先 |
| 空堂节数 | 每天第一节到最后一节之间，总跨度减去有课节数 | 少优先 |
| 最大连续节数 | 单日连续占用大节数的最大值 | 少优先 |
| 最晚结束节次 | 所有安排中最大的结束大节编号，无课为 0 | 早优先 |
| 空闲半天数 | 每周每天上午 1-2 节、下午 3-4 节完全无课各记一次；晚课不占用白天半天 | 多优先 |

夜间 5-6 节仍计入上课天数、空堂、连续节数和最晚结束节次。完全空课表的前五项为 0，空闲半天数为学期周数 × 7 × 2。

## 源文件与调用关系

- `Schedule.h/.cpp`：方案携带六项 `ScheduleMetrics`，提供显示文本。
- `ScheduleEvaluator.h/.cpp`：计算指标、校验六项优先级排列、按字典序比较；指标相同按教学班 ID 序列排序。
- `BoundedMaxHeap.h`：固定容量 K 的大根堆，堆顶始终是保留方案中最差的一个。新方案优于堆顶时才替换，取出时按从优到差排列。
- `ScheduleGenerator.cpp`：沿用 DFS、MRV 与邻接表前向检查；每找到一个完整方案就评价并入堆。维护合法方案总数，堆满不停止搜索。
- `ScheduleValidator.cpp`、`BruteForceGenerator.cpp`：方案先评价再校验；校验器复核保存的指标。暴力枚举继续作为小规模对照。
- `ConstraintPanel.cpp`：调整优先级和恢复默认，只读账号禁用修改按钮。
- `CandidatePanel.cpp`：显示 K、指标、合法方案总数和完成状态。
- `JsonProjectStore.cpp`：保存 `constraints.preferences`，已有 version 4 文件缺少该字段时采用默认顺序。

## 搜索完成状态

`Complete` 表示全部搜完且合法方案数不超过 K；`SolutionLimit` 表示全部搜完且只保留较优的 K 个，两者的 `complete()` 均为 true。`NodeLimit` 与 `Cancelled` 表示未完成，当前结果只是已探索部分中的较优方案，不能宣称全局 Top-K。

本阶段只进行必要编译与小样例功能验证，不增加测试目录、测试框架或构建检查入口。
